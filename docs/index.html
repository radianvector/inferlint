inferlint

inferlint measures what your inference server actually did—and flags what it didn't tell you.

Around a vLLM benchmark it reads the server's boot log and counters, measures achieved concurrency, preemptions, KV-cache use, GPU state and timing, and checks the run for 15 known problems. It works with the load tool you already use.

  • 10 of 32requests ran at once; the benchmark said 32 (T8)
  • 22preemptions, and no line about them in the server log (T1)
  • 10 → 7the most that fit, falling as answers grew (T9)

One command around your benchmark

# install
pipx install inferlint

# start the server, record it while the benchmark runs, check it, stop it
inferlint xray -o run/ --serve "vllm serve MODEL" -- vllm bench serve --model MODEL --max-concurrency 32 ...
