inferlint

inferlint measures what your inference server actually did—and flags what it didn't tell you.

It reads a vLLM server's start-up log and counters around a benchmark, measures achieved concurrency, preemptions, KV-cache use, GPU state and timing, and checks the run for 14 known problems. It works alongside whatever load tool you already use.

pipx install inferlint
